# Badge

> Badge er en ikke-interaktiv komponent som viser status med eller uten tall. Bruk tag dersom du skal ha tekst i stedet for tall.

<br />

## Kode

<Canvas of={stories.Default} />

## Skikk og bruk

<Example>
  <Example.Do text="Tall som skal vise antall nye meldinger, varsel eller oppgaver.">

    <Badge.Position>
      <Badge data-color="accent" count={199} />
      <Button data-color="accent" data-variant="secondary">
        <InboxIcon title="Innboks" /> E-post
      </Button>
    </Badge.Position>

  </Example.Do>

  <Example.Dont text="Det trengs tekst i stedet for tall, bruk heller tag.">
    <Badge.Position>
      <Badge data-color="accent" count={"Hundreognittini"} />
      <Button data-color="accent" data-variant="secondary">
        <InboxIcon title="Innboks" /> E-post
      </Button>
    </Badge.Position>
  </Example.Dont>
</Example>

## Farger

Bruk `data-color` for å endre farge.
<Canvas of={stories.Variants} />

## Flytende over element
Du kan sette plassering med `placement` for å plassere badge over et element, for eksempel en knapp. Bruk `--mtdsc-badge-offset` for å flytte badge innover i elementet.
