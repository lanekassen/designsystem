# Input
>Input er et skjemaelement for å samle inn brukerdata. Det tilbyr grunnleggende funksjonalitet og er ideell når du trenger full kontroll over komponentens oppsett og validering, noe som gjør den ideell for bygging av spesialtilpassede elementer.
<br/>

## Kode
<Canvas of={stories.Default} />

## Skikk og bruk

### Tekstfelt
<Example>
  <Example.Do text="Plasser tekstfelt over hverandre, slik at det er lettere å navigere mellom komponentene og skanne innholdet.">

    <Fieldset>
        <Label>Label</Label>
        <Input />
    </Fieldset>

  </Example.Do>

  <Example.Dont text="Unngå plassering av tekstfelt ved siden av hverandre. Skannbarheten blir dårligere.">

    <Fieldset>
      <Label>Label</Label>
      <Input/>
    </Fieldset>

  </Example.Dont>
</Example>
