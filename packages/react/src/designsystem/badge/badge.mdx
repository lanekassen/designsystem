# Badge
>Badge er en ikke-interaktiv komponent som viser status med eller uten tall. Bruk tag dersom du skal ha tekst i stedet for tall.
<br/>

## Kode
<Canvas of={stories.Default} />

## Skikk og bruk
<Example>
  <Example.Do text="Tall som skal vise antall nye meldinger, varsel eller oppgaver.">

      <Badge data-color="accent" count={199} />

    </Badge.Position>
  </Example.Dont>
</Example>
